# Nupur-Birthday 🌸

A premium, interactive birthday celebration web app built for Nupur.

## Features
- **Personalized Hero Section**: A stunning greeting with floating roses and celebratory interactions.
- **Blow Out Your Candles**: An interactive 3D-styled cake where you can actually blow out the candles.
- **Birthday Letter**: A heartfelt digital envelope containing a private message.
- **Memory Album**: A flipping book filled with shared moments and high-quality photography.
- **Timeline of Us**: A visual journey through the most significant milestones of the relationship.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewports.

## Built With
- HTML5 & CSS3 (Custom animations & media queries)
- Vanilla JavaScript
- Google Fonts (Playfair Display, Cormorant Garamond, Dancing Script)
